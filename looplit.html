Looplit

会議録・予定・担当業務を同じworkspaceで管理する。

Looplitは、AI議事録、会社・チームの予定、担当業務を、会議から実行まで一つの運用フローとしてつなぐWeb workspaceです。

2026Product Design / UX Strategy / DevelopmentNext.js / Supabase / OpenAIWeb

01 / Problem

会議録、予定、担当業務が別々のツールに保存される。

会議後に同じ決定事項をカレンダーとタスク管理ツールへ再入力していました。転記後は元の発言を確認しにくくなります。

01

記録と実行の分断

議事録に残したNext stepが、担当業務へ変わらず止まる。

02

情報の再入力

同じ内容を議事録、カレンダー、タスクへ繰り返し移す。

03

根拠の消失

要約だけが転記されると、判断に使った原文へ戻りにくい。

02 / Connected Operating Flow

録音、整理、予定、担当、フォローアップを順番に接続する。

会議で記録した決定事項を、確認した後に予定や担当業務へ登録できる流れにしました。

→
04Assign担当業務
→
05Follow up進捗確認

03 / Human Review

AIが要約、決定事項、Action candidateを作成し、人が確認する。

会議音声を話者つきで文字起こしします。AIが作成した候補には担当者や期限を自動確定せず、確認後の内容だけを業務へ登録します。

  • 要約と決定を全文Transcriptへ接続
  • Next stepは確定前の候補として表示
  • 承認後に担当者、期限、優先度、状態を付与

Interaction Boundary

AIが提案する範囲と、人が確定する範囲を分けた。

担当者や期限を自動登録すると、誤った候補がそのままチームの予定や業務になります。候補の生成と業務への反映の間に確認操作を置きました。

AIExtract

要約・決定・Next stepを候補化

→
SystemUnconfirmed

担当者と期限を未確定で表示

→
HumanEdit / Confirm

内容、担当者、期限を確認

→
WorkspaceRegister

確認した内容だけ予定・業務へ登録

Trade-off 確認操作が1段階増える代わりに、AIの推測とチームの確定情報を同じ状態にしない。

04 / Product Principles

議事録の決定事項を、予定と担当業務に接続する。

会議、予定、担当業務をチームとプロジェクトに紐づけ、同じ内容を再入力する工程を減らしました。

Connected

一度記録し、続けて使う

議事録の決定とNext stepを、予定や担当業務へつなげる。

Human Review

提案と確定を分ける

AI出力をそのまま反映せず、人の確認を操作として残す。

Team Context

誰の仕事かを保つ

会議、予定、業務を関係するチームとプロジェクトへ紐づける。

05 / Current Outcome

録音から担当業務の登録までをWeb productに実装した。

話者つき文字起こし、構造化されたAI結果、Transcript Reference、予定、担当業務を一つのworkspaceに実装しました。公開利用指標はまだなく、現在は情報の接続とHuman Reviewを検証しています。

AIが抽出した決定事項は、自動反映せず、確認後に予定や担当業務へ登録する。
