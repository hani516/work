Blinq

予定と支出を同じカレンダーに表示する。

Blinqは、家計簿とカレンダーを統合し、同じ日付の予定と支出を確認できるモバイルアプリです。

2025.03 - 2025.08Product Design / UIUX / Visual Design1 Designer / 1 DeveloperMobile

01 / Problem

金額は分かっても、なぜ使ったのかを振り返れない。

家計簿は支出カテゴリを、カレンダーは予定を記録します。しかし旅行、通院、会食のように予定と支出が結びつく場面では、二つのアプリを行き来しなければ文脈を確認できませんでした。

01

支出の背景が見えない

金額とカテゴリだけでは、その支出が発生した日の行動を思い出しにくい。

02

アプリ切り替えの手間

予定と支出を別々に記録するため、確認と入力のたびに移動が発生する。

03

次の支出を予測しにくい

過去の予定と支出が分離されていると、似た予定に必要な金額を見積もりにくい。

02 / Information Model

日付を基準に、予定と収支を一つの画面に表示する。

カレンダー上部に予定、下部に収支を置き、同じ日付の出来事と金額を同時に確認できる構造にしました。

Dashboard

統合・家計簿・スケジュールの3表示を切り替える。

3つの表示を同じカレンダー基盤で構成し、選択した日付の詳細を画面内で確認できるようにしました。

  • 統合: 予定と収支を同時に表示
  • 家計簿: 月の収入・支出と明細を表示
  • スケジュール: 予定のみを表示

03 / UX Iteration

ホームボタンでのモード切替は、操作方法が分かりにくかった。

リリース後の行動観察で、ホームボタンを押すたびに3種類のカレンダーが切り替わることを理解しにくいと確認しました。

Observation同じHomeボタンが3つの表示を切り替えていた。

押した後に何が表示されるかを、操作前に判断できなかった。

Diagnosis問題は情報モデルではなく、移動先の見せ方だった。

日付で予定と収支を統合する構造は維持し、ナビゲーションだけを変更した。

Decision5つの移動先をTab Barに表示した。

項目数は増えるが、現在地と移動先を操作前に確認できる。

Before → After

切替式の3タブを、予算、家計簿、ホーム、スケジュール、設定の5項目に変更しました。

04 / Learning

隠れていたモード切替を、5つのTab Bar項目に変更した。

ホームボタンを繰り返し押す操作では移動先が分かりにくかったため、予算、家計簿、ホーム、スケジュール、設定を個別に表示しました。
